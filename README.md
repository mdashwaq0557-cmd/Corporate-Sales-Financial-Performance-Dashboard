# Corporate-Sales-Financial-Performance-Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze corporate sales, revenue, costs, profitability, discounts, and product performance.

## Dashboard Pages

### 1. Corporate Financial Overview
- Total Sales and Total Profit
- Monthly Sales and Profit Trends
- Sales by Business Segment
- Profit by Country

### 2. Revenue & Margin Analysis
- Discounts by Product
- COGS versus Sales
- Monthly Profit Margin Analysis
- Financial KPI Monitoring

### 3. Segment & Product Performance
- Sales by Business Segment
- Country-wise Profit Analysis
- Product Performance Matrix
- Segment-wise Gross Profit Analysis

## How to Use
1. Clone or download this repository.
2. Open the corporate.pbix file using Microsoft Power BI Desktop.
3. Refresh the data if the original data source is available.
4. Explore the dashboard using interactive filters.
